# VGO Framework 中文说明

**GEO 关注品牌在生成式 AI 答案中的表现；VGO 优化品牌在整个机器世界的有效可见度增长结果。**

VGO（Visibility Growth Optimization，可见度增长优化）是面向整个机器世界、以有效可见度增长结果为目标的开放**行动框架**。它覆盖 GEO 所关注的生成式 AI 可见度优化，并统合 SEO、AEO 及新兴机器发现入口。VGO 从真实用户意图和可验证的品牌事实出发，指导组织诊断机器认知、制定增长方案、执行优化行动、验证效果并持续学习；在适合的环节推进自动化，同时将事实、证据、内容、数据和经验沉淀为品牌可长期持有的资产。

**行动闭环：诊断 → 决策 → 执行 → 验证 → 学习。**公开框架定义行动方法、证据要求和自动化边界；Omseek 开发独立的产品实现。本仓库是方法论和执行指引，不是可安装的 AI 助手或工作流引擎。

## 什么是 VGO？

VGO 是一套开放方法论，以**真实用户需求与高价值意图**为起点，系统提升企业、品牌、产品、人物或内容在搜索、生成式 AI 及新兴发现入口中的**有效、可信、可持续可见度**，并将优化过程中形成的内容、知识、证据、数据与经验沉淀为长期增长资产。

> **北极星：增长更多有效可见。**
>
> **不是更多可见，而是更多有效可见。**

VGO 不从平台、Prompt 数量或原始曝光数字出发，而先理解真实用户是谁、他们有什么需求、哪些问题真正影响认知、比较与决策。

## 从衡量走向行动

VGO 不只是概念或指标体系。它指导组织对照可验证事实诊断机器认知差距，围绕有价值的用户意图确定优先级，在自有资产和可信外部信源上执行优化，复核变化，并把证据用于下一轮决策。详见 [行动框架](VGO-FRAMEWORK.md#11-operating-loop) 和 [能力关系](SEO-GEO-VGO.md)。

| 环节 | 必须形成的产出 |
|---|---|
| 诊断 | 意图场景、机器当前表达、品牌事实、证据和差距 |
| 决策 | 有价值依据、限制和风险的机会优先级 |
| 执行 | 基座、事实、证据、内容或信源的变更及责任、审核点 |
| 验证 | 可比观察、事实核验、局限和反面证据 |
| 学习 | 行动结果记录及下一轮调整后的优先级 |

自动化可辅助各环节，但必须保留证据、责任和适当审核。框架不声称某个软件已经自动完成所有步骤。

## 核心价值链

**真实用户与高价值意图 → 有效资产 → 有效 SEO + 有效 AEO + 有效 GEO → 有效可见 → 信任 → 比较 → 推荐 → 选择 → 衡量 → 优化 → 学习 → 长期增长资产**

概念上：

**有效可见 = 对的人 × 对的意图 × 对的入口 × 对的出现**

这是概念模型，不是统一的商业评分公式。

## 五个核心概念

- **有效资产（Effective Assets）**：围绕真实用户需求与高价值意图建立、由企业拥有或控制，并能够持续参与搜索、AI、发现与决策过程的资产。
- **有效 SEO（Effective SEO）**：围绕真实用户需求与高价值搜索意图建立的搜索可见能力，使企业在有价值的搜索场景中被正确发现、理解，并进一步进入用户决策过程。
- **有效 AEO（Effective AEO）**：围绕真实用户问题，让准确、有用、可验证的信息在搜索与 AI 等直接回答界面中被正确选取和呈现。单次进入答案不等于准确或有效。
- **有效 GEO（Effective GEO）**：品牌在真实用户、高价值生成式问题空间中，被生成式 AI 正确理解、可信引用、合理比较与推荐的能力。
- **有效可见（Effective Visibility）**：在正确受众、正确意图、正确入口和正确出现方式共同作用下产生的有价值可见。

**有排名 ≠ 有效 SEO。被提及 ≠ 有效 GEO。可见 ≠ 价值。**

## VGO 与 SEO / AEO / GEO

**VGO 覆盖 GEO 所关注的生成式 AI 可见度能力，并在入口范围、有效性、资产主权和长期学习方面扩展行动范围。**这里的上层关系来自覆盖范围与评估维度，并不意味着 GEO 不重要，也不承诺 VGO 必然带来更高排名、更多引用、更多推荐或更高收入。VGO 保留 GEO 对生成式系统的观察，同时将跨入口协同、意图相关性、证据质量、信息完整性、可观察的结果与长期自有资产纳入判断。

SEO、AEO、GEO 是 VGO 中相互关联的能力视角：SEO 关注搜索发现；AEO 关注直接答案中的呈现与准确性；GEO 关注生成式系统如何理解、引用、比较和推荐。生成式系统生成答案时，AEO 与 GEO 会重叠。三者不是互斥渠道，也不构成必须依次完成的流程。

VGO 把这些观察放回真实用户需求、决策意图、企业资产、权威、信息完整性、衡量与结果之中。排名、进入答案、提及和引用都只是中间信号，单独不能证明用户选择或商业价值。详见 [能力关系文档](SEO-GEO-VGO.md)。

## 常见问题

**VGO Framework 是做 GEO 的开源软件吗？**不是。本仓库公开的是采用 CC BY 4.0 授权的方法论、评估原则与文档，不提供 AI 助手或工作流自动化引擎。产品实现属于独立层面。

**VGO 是 GEO 的另一种叫法吗？**不是。GEO 聚焦生成式系统；VGO 纳入 GEO、SEO、AEO 等能力，并判断可见是否相关、准确、可信及有助于决策。单次 AI 回答可能同时涉及 AEO 和 GEO。

**VGO 会取代 GEO 吗？**不会。GEO 是 VGO 框架中的独立能力领域，VGO 为跨入口的优先级与结果评估提供更广的视角。

**Omseek 和 VGO 是什么关系？**Omseek 发起并维护开放框架，同时开发独立的产品实践平台；产品功能不等于本仓库提供的软件功能。

## 自有资产与第三方信号

第三方来源承担分发、独立佐证、引用、权威与信源多样性；自有资产承担企业事实、知识、内容、证据与长期积累。

> **永久拥有的资产，持续变化的可见度。**

VGO 不承诺排名、AI 引用或流量永久复利。可持续积累的是企业拥有的内容、知识、实体关系、数据、历史表现、优化经验与组织能力。

## Visibility Surface

Visibility Surface（可见度入口）是任何能够影响发现、理解、引用、比较、推荐或选择的数字界面、系统、平台、智能体或设备。

VGO v1 当前重点关注搜索与生成式 AI，同时保持对未来发现入口的开放性。

## 衡量

VGO 区分原始曝光与有效可见。公开框架描述衡量原则、概念和可验证标准，但不公开商业实现中的专有权重、意图发现算法、机会优先级算法、自动化策略或产品实现配方。

单场景公开判定见可供测试的草案 [EVALUATION-PROTOCOL.md](EVALUATION-PROTOCOL.md)。该草案不是通用认证，也不定义统一分数。
