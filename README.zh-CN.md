# VGO Framework 中文说明

**VGO — Visibility Growth Optimization（可见度增长优化）**

[English](README.md) · [核心框架](VGO-FRAMEWORK.md) · [指标体系](METRICS.md) · [公开评估规范](EVALUATION-PROTOCOL.md) · [原则](PRINCIPLES.md)

## 什么是 VGO？

VGO 是一套开放方法论，以**真实用户需求与高价值意图**为起点，系统提升企业、品牌、产品、人物或内容在搜索引擎、答案引擎、生成式 AI、智能代理及新兴发现入口中的**有效、可信、可持续可见度**，并将优化过程中形成的内容、知识、证据、数据与经验沉淀为长期增长资产。

> **北极星：增长更多有效可见。**
>
> **不是更多可见，而是更多有效可见。**

VGO 不从平台、Prompt 数量或原始曝光数字出发，而先理解真实用户是谁、他们有什么需求、哪些问题真正影响认知、比较与决策。

## 核心价值链

**真实用户与高价值意图 → 有效资产 → 有效 SEO + 有效 AEO + 有效 GEO → 有效可见 → 信任 → 比较 → 推荐 → 选择 → 衡量 → 优化 → 学习 → 长期增长资产**

概念上：

**有效可见 = 对的人 × 对的意图 × 对的入口 × 对的出现**

这是概念模型，不是统一的商业评分公式。

## 五个核心概念

- **有效资产（Effective Assets）**：围绕真实用户需求与高价值意图建立、由企业拥有或控制，并能够持续参与搜索、AI、发现与决策过程的资产。
- **有效 SEO（Effective SEO）**：围绕真实用户需求与高价值搜索意图建立的搜索可见能力，使企业在有价值的搜索场景中被正确发现、理解，并进一步进入用户决策过程。
- **有效 AEO（Effective AEO）**：在有价值的问题场景中，提供准确、可提取、可验证、适合引用的答案，使其具备被答案入口选择和呈现的能力。
- **有效 GEO（Effective GEO）**：品牌在真实用户、高价值生成式问题空间中，被生成式 AI 正确理解、可信引用、合理比较与推荐的能力。
- **有效可见（Effective Visibility）**：在正确受众、正确意图、正确入口和正确出现方式共同作用下产生的有价值可见。

**有排名 ≠ 有效 SEO。被提取 ≠ 有效 AEO。被提及 ≠ 有效 GEO。可见 ≠ 价值。**

## VGO 与 SEO / AEO / GEO

SEO、AEO 和 GEO 是彼此不同但相互交叉的重要能力域，VGO 是连接它们与真实用户意图、企业资产、权威、完整性、衡量及业务结果的上层增长框架。

**SEO 提升被发现，AEO 提升答案资格与答案采信，GEO 提升生成式系统中的理解、引用、比较与推荐，VGO 将三者统一到有效可见与结果。**

VGO 不否定 SEO、AEO 或 GEO，也不把它们混为同义词或强制线性漏斗。SEO 与 AEO 经常为 GEO 提供技术、内容和答案资产基础，但并非每一种 GEO 结果都必须依次经过 SEO 与 AEO。

## 自有资产与第三方信号

第三方来源承担分发、独立佐证、引用、权威与信源多样性；自有资产承担企业事实、知识、内容、证据与长期积累。

> **永久拥有的资产，持续变化的可见度。**

VGO 不承诺排名、AI 引用或流量永久复利。可持续积累的是企业拥有的内容、知识、实体关系、数据、历史表现、优化经验与组织能力。

## Visibility Surface

Visibility Surface（可见度入口）是任何能够影响发现、理解、引用、比较、推荐或选择的数字界面、系统、平台、智能体或设备。

VGO v1 当前重点关注搜索、答案与生成式 AI，同时保持对智能代理及未来发现入口的开放性。

## 衡量

VGO 区分原始曝光与有效可见。公开框架描述衡量原则、概念和可验证标准，但不公开商业实现中的专有权重、意图发现算法、机会优先级算法、自动化策略或产品实现配方。

单场景公开判定见可供测试的草案 [EVALUATION-PROTOCOL.md](EVALUATION-PROTOCOL.md)。该草案不是通用认证，也不定义统一分数。
