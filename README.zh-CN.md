# VGO Framework 中文说明

**VGO — Visibility Growth Optimization（可见度增长优化）**

[English](README.md) · [阅读副本](https://www.vgoframework.org/docs) · [核心框架](VGO-FRAMEWORK.md) · [指标体系](METRICS.md) · [完整性与投毒防御](INTEGRITY-AND-DEFENSE.md) · [参与贡献](CONTRIBUTING.md)

## 什么是 VGO？

VGO 是一套开放方法论，以**真实用户需求与决策意图**为起点，用于系统性提升品牌、企业、产品、人物或内容在**搜索引擎、生成式 AI、答案引擎、智能体以及新兴发现入口**中的**有效、可信、可持续可见度**。

VGO 的基本视角是：

> **先盯人，再盯问题；先盯意图，再盯可见度。**

因此，VGO 不从平台、Prompt 数量或曝光数字出发，而先理解真实用户是谁、需求如何产生、他们会提出什么问题，以及哪些问题真正影响认知、比较与决策。

核心价值链可以概括为：

**真实用户 → 真实意图 → 高价值问题空间 → 被发现 → 被正确理解 → 被提及 / 引用 → 被信任 → 被比较 → 被推荐 → 被选择 → 形成可持续增长资产。**

VGO 不取代 SEO，也不把 GEO 改一个名字。SEO 面向搜索发现与第一方内容资产，GEO 面向生成式/答案系统中的理解、提及、引用与推荐；VGO 位于更高一层，把用户意图、SEO、GEO、实体与权威、内容与分发、技术可访问性、衡量、完整性以及长期增长统一到一个跨入口框架中。

> **北极星：增长有效且可信的可见度，而不是不惜代价地追求曝光。**

**Visibility ≠ Value. 可见度不天然等于价值。**

## 七大核心支柱

1. **Search Visibility** — 搜索可见度
2. **Generative Visibility** — 生成式 AI 可见度
3. **Entity & Authority** — 实体与权威
4. **Content & Distribution** — 内容与分发
5. **Technical Accessibility** — 技术可访问性
6. **Measurement & Growth** — 衡量与增长
7. **Visibility Integrity & Poisoning Defense** — 可见度完整性与投毒防御

## 核心运行闭环

`发现 → 诊断 → 排优先级 → 优化 → 分发 → 验证 → 防御 → 衡量 → 学习`

VGO 不把“曝光增加”视为工作的终点。增长后的结果还需要验证其**需求相关性、准确性、权威性、来源可追溯性、完整性和实际业务价值**。

## VGO 与 SEO / GEO

SEO 和 GEO 是重要的能力域，VGO 是更上层的增长框架。

GEO 本身不是问题。问题在于，如果只用 Prompt 覆盖率、提及次数或原始曝光衡量 GEO，就可能把“容易获得的可见度”误认为“真正有价值的可见度”。VGO 因此强调：不同问题、意图和发现机会的价值并不相同。

一个技术健全、权威且结构清晰的自有网站可以增强搜索发现，也可以为机器提供稳定、可引用的第一方事实；与此同时，生成式系统也可能依赖第三方来源和其他数据管道。因此 VGO 不把 SEO 视为 GEO 的普遍前置条件，而是把两者放入同一套用户意图与增长框架中。

## 自有资产与外部信号

VGO 同时重视第一方资产和可信的第三方信号。

**第三方来源承担分发、独立佐证、引用、权威与信源多样性；自有网站与第一方内容承担实体、产品、服务、知识、案例、事实和长期内容资产。**

目标不是只在外部平台“租用”可见度，而是逐步形成企业自己拥有、能够持续维护和观察的可见度资产。

## 可见度完整性

VGO 将错误信息、过期事实、实体混淆、恶意内容、不可信来源、虚假共识以及针对检索/生成系统的操纵视为正式的可见度风险。

防御闭环：

`基线 → 观察 → 检测 → 验证 → 分类 → 响应 → 再验证 → 恢复`

VGO 的防御体系不包含攻击性投毒、伪造内容、虚假评论、冒充、黑客攻击或绕过第三方安全机制。

## 发起与治理

**VGO Framework 由 Omseek 于 2026 年发起，并作为开放方法论持续维护。**

Omseek 是 founding maintainer。社区可以通过 Issues 和 Pull Requests 提交研究、修正、指标、案例和框架提案；维护者负责版本一致性、定义、治理与框架完整性。

**VGO 是开放方法论；Omseek 是其发起者、维护者与产品化实践平台。**
