# VGO Roadmap

## 1.0 — Foundation
- Core definition and seven pillars
- SEO/GEO relationship
- Metric vocabulary
- Visibility integrity & poisoning defense
- Governance and contribution model

## 1.1 — Measurement specification
- Sampling protocol for queries/prompts
- Cross-model/cross-engine normalization
- Confidence intervals and repeatability guidance
- Source/citation classification

## 1.2 — Entity & provenance specification
- Canonical entity record
- Evidence/provenance schema
- Change and freshness model

## 1.3 — Integrity specification
- Threat taxonomy
- Anomaly severity model
- Recovery-state model
- Incident reporting template

## 2.0 — Multi-surface VGO
- Agents and autonomous discovery
- Multimodal discovery
- Commerce/vertical assistants
- Machine-to-machine discovery
