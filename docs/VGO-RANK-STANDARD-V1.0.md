# VGO Rank v1.0 冻结标准

**决议日期：2026-09-29**  
**状态：规范冻结；正式证书须通过本文件的首发验收门槛后签发**  
**标准与签发主体：VGO Framework；首个应用方：Omseek**

## 1. 定义、对象与边界

VGO Rank（等级代号 VR0—VR10）衡量一个可核实的品牌或产品实体在指定市场、语言及行业问题空间的机器介导发现、正确理解、可信呈现和合理推荐的有效可见表现。它不是企业实力、产品质量、商业收入、搜索平台官方评级或未来增长保证。

每份评级的不可省略的作用域为 `entity_id / entity_type / market / locale / industry / question_space_version / surface_protocol_version / window / rank_protocol_version`。品牌与产品分别评级；城市与全国分别评级；不同作用域或版本的数字不得直接排列。无网站可评级，网站基座健康指数 VHI 单列，不直接给 VR 加分；访问和询盘单列为效果验证，不参与 VR。

正式等级是整数 VR0—VR10，未评级为 `unrated`，绝不写作 VR0。内部连续分数 S 为 0—100，公开证书可展示 S、区间和证据覆盖率作为解释，但市场传播的主结果始终为等级。VR 不是全球权重，也不存在跨市场总分。

## 2. 实体、题目与市场队列

实体须有至少两条彼此独立的身份或经营证据，其中至少一条为实体自有或权威登记证据；同名实体、集团、产品、改名、收购须独立消歧。未认领实体可评级及提出纠错；认领及购买服务均不得改变抽样规则。

每一 `market × locale × industry` 发布一个问题空间：高价值意图及分层权重在采样前封存。正式题库按品牌导航 15%、类别发现 35%、问题与比较 35%、交易或选择 15% 抽样；如行业不适用交易题，其 15% 预先等比例分配给发现与比较，并记录新问题空间版本。问题由真实问法、行业专家与变体构成；单一客户供题不得超过正式题库 5%。客户诊断题、正式保密题、保留验证题互不重叠；正式题不少于 120 道，其中至少 25% 每期轮换，保留验证题不少于 30 道。固定题复测与未见题泛化分别报告；泄露题目立即换题并标记版本断点。

评级分母使用预先登记的全部合格问题机会，不按实体出现结果倒选题；品牌导航题的分层贡献最多 15%。采样必须声明设备/位置、平台入口、模型或索引版本、日期、语言、提示模板、原始输出与解析版本。不得用 mock 观测签发生产评级。

## 3. 观测面与有效样本

首发协议包含搜索、AI/答案、社交发现三观测面；搜索与 AI 为必需面，社交如该市场无合规、稳定、可复行入口则在市场协议发布前整体移除，重新归一权重，不允许对单个付费客户例外。每面至少两个独立入口或提供方；入口失效一律按市场协议处置，不用替代入口私下补齐某实体数据。

正式窗口为连续 30 天，每道正式题在每个适用观测面至少 3 个相隔至少 24 小时的采样批次；每个面至少 240 个合格题目机会，每个意图层至少 30 个；全作用域至少 720 个合格机会。合格机会覆盖预设计划的至少 85%，任一必需面的计划覆盖至少 80%；故障、超时、拒答、被阻断和采集异常不算实体缺席，需补采，不能补足即 `unrated`。不同入口不能仅由同一底层结果的镜像构成独立互证。

每个合格机会记录出现 P、正确理解 U、可信证据 C、合理推荐 R 四个布尔或不适用值；另记访问 V、采集质量、证据 ID。实体错误归属、关键事实错误或不适配推荐不计相应有效成功。纯信息题的推荐为不适用，非零分；没有显式引文的界面可以用可核查、独立、事实一致的信源判定可信证据，但必须披露判定方法。结果为主观广告、付费位置时单列标记，不计自然观测成功。判定须基于保存的原始输出和可回看的证据。

## 4. 计算公式（v1.0）

每个合格机会的质量分 `q = 0.20P + 0.30(P∧U) + 0.25(P∧U∧C) + 0.25(P∧U∧R)`。推荐不适用时，将末项 0.25 按前面三项的原始比例归一到 1；可信证据确属平台不适用时须由整个市场协议统一处理，不得实体级豁免。关键事实严重错误、同名错认或不适配推荐导致 `U=0` 或 `R=0`，不得用出现量获得高等级。

各面得分为按照预注册意图层和题目权重计算的 q 均值。首发固定合成权重：搜索 35%、AI/答案 45%、社交 20%；市场协议整体移除社交时搜索 43.75%、AI 56.25%。`S_raw = 100 × Σ(观测面权重 × 面得分)`。以题目为聚类单位进行 2,000 次固定种子的分层 bootstrap，得到 S 的双侧 90% 置信区间 `[L,U]`；缺失与入口相关性通过原始采样记录披露，不假装独立。正式定级使用保守分数 `S*=L`，保留 S_raw 供解释。

诚信与准确性闸门先于等级阈值：合格出现机会中的关键事实正确率低于 80%，最高 VR2；80%—89.99%，最高 VR4；90%—94.99%，最高 VR6；达到 95% 才能进入 VR7+。有效非品牌机会占全部非品牌机会低于 5% 时最高 VR2，低于 15% 时最高 VR4；AI 面有效机会低于 10% 时最高 VR4。证据来源存在已核实的系统性伪造、批量操纵或严重实体错认时暂停签发进入 restricted 调查，不能以惩罚性随意扣分代替调查程序。

## 5. 等级阈值与稳定性

按 S* 的如下闭区间下限定基础等级，随后应用准确性、非品牌、AI 闸门，取最低结果：

| 等级 | S* 下限 | 语义 |
| --- | ---: | --- |
| VR0 | 0 | 合格采样下基本不可见 |
| VR1 | 5 | 极少有效出现 |
| VR2 | 12 | 零星可见 |
| VR3 | 20 | 部分问题有效出现 |
| VR4 | 30 | 初步覆盖核心问题 |
| VR5 | 42 | 多类意图有效可见 |
| VR6 | 54 | 核心问题稳定有效可见 |
| VR7 | 66 | 多面持续可信表现 |
| VR8 | 76 | 高覆盖与高准确表现 |
| VR9 | 85 | 长期市场领先，另需连续 3 期满足阈值及闸门 |
| VR10 | 93 | 广泛可复核的标杆，另需连续 6 期满足阈值及闸门 |

初次正式发布最多签发 VR8；VR9、VR10 开放须经至少两个自然季度试运行、独立审计及结果效度报告通过，并在新协议版本明确公告。门槛是绝对值，不设固定名额。同业分位仅在同一版本、同一作用域至少 30 个合格实体时展示，且只作背景说明，不改变等级。

每月签发一次，首次合格即可定级。正常升一级须连续两期达到新级的 S* 下限；正常降一级须连续两期低于当前级下限减 2 分；一次最多升降一级，每期仍保留真实 S* 和原始观测以免掩盖变化。首次签发按当期基础等级，不受单级限制；显著身份错认、证据伪造、协议失效及重大事实纠错走非常规复核，即时限制或撤销，不等待两期。重大平台/问题空间/权重变更为新序列，不跨断点显示升降箭头。阈值不得追溯修改历史证书。

## 6. 状态、证书、申诉

`unrated` 表示未具备资格；`provisional` 为试验结果，无正式徽章或榜单；`rated` 为有效证书；`watch` 为连续性或质量异常但原证书有效，附显著提示；`restricted` 暂停现行等级引用，展示上期历史值及原因；`revoked` 撤销错误或违规签发的具体证书，保留公开历史。证书签发后有效 45 天，30 天滚动窗口月度更新；逾期未重签自动过期，不能继续使用动态徽章。

证书载明实体和作用域、VR 等级、S_raw、S*、90% 区间、各面样本及覆盖、准确性闸门、版本、签发时间、有效期、状态、四种角色（标准制定、数据提供、计算签发、申诉裁决）、利益关联、签名与公开验证地址。原始内容仅在授权与版权范围向权利人/审计方提供；公众至少可核查摘要、状态和版本。

实体及受影响第三方均可免费纠错。收到申请 3 个工作日内确认；明显身份或事实错误 5 个工作日内先行限制和核查；普通申诉 15 个工作日内作出附理由决定，复杂案告知延期且总计不超过 30 个工作日。签发计算者不得单独裁决自己的争议；关联主体回避，独立复核人留审计记录。必要时撤销并重签，历史和纠错说明公开，已发订阅事件通知下游。

## 7. 治理、反操纵与发布门槛

VGO Framework 制定规则、控制评级服务及签名密钥、签发证书；Omseek 和其他授权使用方走同一正式接口。付费不影响抽样、分数、申诉或榜单排序。Framework 与 Omseek 的关联、审计主体及四种角色须显著披露；未达到组织独立条件前，不使用“独立第三方权威评级”表述。

题目泄露、批量伪造信源、同源伪装多源、付费位置混入自然结果、异常引用环及针对采样入口的特供内容均触发调查。抽检每期至少 10% 的出现机会及全部疑似严重错误；关键争议由两名判定者独立复核，分歧交第三人，记录一致率。申诉和撤销只依据证据，不以负面舆情热度自动扣分。

首发只选一个明确定义的中国中文行业问题空间及市场。签发前必须有至少 30 个可比较且经消歧的实体；两轮完整的 30 天试运行；有效采样覆盖合格率至少 95% 的待签实体达到第 3 节门槛；双人判定 Cohen’s κ ≥ 0.75；随机抽取 10% 机会的关键事实判定一致率 ≥ 90%；同条件重复采样的面得分差异中位数 ≤ 5 分；无重大系统性偏差；完成相关法律审查、关联披露、证书撤销演练及可公开校准报告。未满足任一门槛，只可发布诊断、VHI 和明确标注的试验等级，不可签发正式 Rank 或榜单。这是发布验收，不是另留评分规则待定。

标准重大修改提前 30 天公告并升协议版本；安全或明显错误可紧急修正，公告原因和影响范围。每年发布覆盖、判定、稳定性、等级分布、申诉翻案、防操纵误报和与实际业务结果关联的报告。实际转化仅用于验证预测效度，不能宣传为 Rank 导致收入增长。

## 8. 对外固定说法

**VGO Rank 是由 VGO Framework 按公开版本协议，对特定市场和问题空间的有效机器可见度进行观测和评级的 VR0—VR10 等级。**其结果附证据覆盖、有效期及纠错入口。Omseek 是首个应用方，与 Framework 有关联；正式等级由 Framework 服务签发。首发验收完成前只称“VGO Rank v1.0 冻结标准／试验评级”，不得展示正式认证徽章。

**冻结范围**：本文件的定义、题库比例、采样、公式、权重、门槛、状态与发布条件全部冻结。未来经验数据可促成 v1.1 或 v2.0，但必须公开变更、平行复算并保持旧证书与版本记录；不得在 v1.0 内私改阈值。
