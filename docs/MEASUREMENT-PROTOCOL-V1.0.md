# VGO Shared Measurement Protocol v1.0
**Status: FROZEN ENGINEERING CONTRACT — 2026-10-01**

An observation opportunity is pre-registered by scope × question/intention stratum × surface × provider/entry × locale/region × collection conditions × scheduled batch. Results cannot be selected after seeing entity performance.

Collection records raw output/quality first; adjudication separately derives P presence, U correct understanding, C credible traceable evidence, R reasonable recommendation, NA+reason, paid placement, identity/factual/integrity flags. Timeout/block/transport/parser failure is collection_failure, never P=0.

Question classes: diagnostic_public; rating_sealed (formal Rank only, inaccessible to customer/partner clients); holdout_validation. IDs, set versions and hashes are immutable. Leakage creates a version event and invalidates affected sealed samples per Rank protocol.

Persist provider/product, visible model/index identifier if available, device/interface, region, language, known personalization/login state, template version, request/response hashes, timestamps, parser/adjudication versions and collection quality.

Diagnosis plans may be faster/smaller but MUST publish denominator, coverage and uncertainty limitations. Formal Rank remains exactly under VGO Rank v1.0. Retry/replacement rules are outcome-blind and audited. Provider failure cannot be selectively replaced for one customer.

Comparisons require compatible entity type, market, locale, question-space, surface protocol, time window and metric protocol. Version breaks are reported, not normalized away. Automated adjudication may propose labels; overrides append actor/reason/prior/new values. Clicks/leads/revenue are separate outcome evidence and do not rewrite observations or Rank.
